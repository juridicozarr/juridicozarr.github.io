A NOTE ON ROUTING

CN2 GIA 是什么？

CN2 GIA 是中国电信 CN2 网络的一种线路选择，并非所有机房都提供。线路名称不能代替实际测试：建议从主要用户所在地区和网络出发，比较不同时段的连接情况。

03 / CHECKOUT

搬瓦工购买教程

准备常用邮箱和支付方式，沿着配置页面完成选择；提交前再核对一次订单。

  1. 01

    准备并选定方案

    确定所需资源和预算，进入对应套餐页面，选择付款周期与可用机房。

  2. 02

    加入购物车

    点击 Add to Cart，检查套餐、数据中心及账单周期。如有优惠码，可在此验证。

  3. 03

    填写账户资料

    进入 Checkout，填写姓名、常用邮箱、密码和账单地址；按页面提示完成账户步骤。

  4. 04

    选择支付并确认

    参考资料列有支付宝、PayPal、信用卡和银联；可用方式以结算页面为准。核对金额和条款后提交订单。

04 / PROMOTIONAL CODE

优惠码怎么用

如果持有优惠码，在购物车的 Promotional Code 输入框填写，点击 Validate Code 验证，并在付款前核对订单金额。

历史状态 / 已失效

留意代码有效期

参考资料将 NODESEEK2026 和 BWHCGLUKKB 标记为已失效。没有优惠码时，也可以留空并继续结算。

05 / AFTER PURCHASE

购买后与常见问题

保留账户邮件，并在管理服务前确认所购方案的功能和限制。

每个套餐都能选择所有机房吗？

不同系列的机房范围不同。选购时查看具体套餐的机房列表与 Datacenter feature highlight，不要仅凭地区名称判断线路。

如何确认实际账单周期？

在配置和购物车页面检查所选周期、首付金额及后续账单信息，再根据自己的使用计划确认订单。

优惠码验证失败怎么办？

检查代码拼写及多余空格；代码可能已过期，或不适用于所选套餐。以结算页面的验证结果为准。
